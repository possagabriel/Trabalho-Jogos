# Artes dos novos guardiões

Artes originais geradas para INCARNATE com o tool integrado `image_gen` em
12/11/2026, sem imagens de referência ou assets de terceiros. Distribuição sob
MIT, a licença deste repositório. Os arquivos PNG preservam o canal alpha da
saída original; os originais gerados foram copiados, sem substituição de artes
anteriores. Cada guardião tem uma imagem própria, reutilizada pelo renderer e
pelas miniaturas. Redimensionamento e rotações são feitos pelo pygame em cache.

| Arquivo | Guardião | Composição |
| --- | --- | --- |
| `prisma.png` | Prisma | Três asas prismáticas, armadura ciano e reator triangular. |
| `oraculo.png` | Oráculo | Oito pétalas blindadas azuis, íris mecânica e núcleo ciano. |
| `obelisco.png` | Obelisco | Fortaleza em losango alongado, reator rosa e armadura violeta. |

Single centered object filling 78% of a square canvas. Genuine transparent background, no scenery, no lettering, no watermark, no cast shadow outside the object, no detached effects. No copyrighted characters. Ship must point upward.
